# HerRhythm — Women's Health & Safety Smartwatch Platform

> **"Your rhythm. Your health. Your safety."**  
> *A smartwatch designed around the unique rhythm of women's health.*

HerRhythm is a health-tech wearable and intelligence ecosystem that integrates continuous biometric telemetry, infradian menstrual cycle intelligence, NYRA AI health companionship, and an active personal safety system into a unified wearable experience.

---

## 🌟 The Three Core Pillars

1. **Women's Health Intelligence**: Continuous biphasic skin temperature, resting heart rate (ECG), SpO₂, and HRV mapped against the 28-day infradian hormonal cycle.
2. **NYRA AI Companion**: An intelligent, empathetic health assistant accessible via voice and chat, capable of generating cycle-synced workouts and providing contextual wellness guidance.
3. **Personal Safety Ecosystem**: A 3-second hold-to-activate emergency SOS trigger, dual-band GPS location broadcast to trusted contacts, "Watch My Journey" live route oversight, and smart safety/wellness alerts.

## ⌚ Key Features

### 1. Interactive Smartwatch Simulator
A virtual smartwatch featuring a metallic titanium/rose-gold chassis, tactile digital crown, side button, and **15+ functional screens**:
- **Watch Home**: Real-time clock, date, live BPM, steps ring, battery, and cycle status.
- **Heart Rate**: Live animated ECG waveform, resting 62 BPM, daily min/max range.

- **Activity & Movement**: Steps (7,842 / 10k), distance (5.2 km), active calories (1,842 kcal).

- **Symptoms Logger**: Interactive wrist-tap chips (Cramps, Headache, Bloating, Fatigue, etc.).
- **Mood Tracking**: Quick emotional state selector (😊 Happy, ⚡ Energetic, 😌 Calm, 😰 Anxious, etc.).
- **Hydration Tracker**: Volume consumed vs goal with an interactive **"+250ml"** tap-to-drink button.
- **Energy Reserve**: 74% peak fuel reserve and cycle metabolic efficiency readout.
- **Recovery Readiness**: 82% optimal readiness score based on overnight HRV.
- **NYRA on Wrist**: On-wrist AI companion insight and voice question prompt.
- **Safety / SOS**: Dedicated hold-to-activate SOS, live GPS lock, and trusted contact link.

## 📦 Getting Started

### Prerequisites
- Node.js (v18+ recommended)
- npm or pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/ekki13-learner/her-rhythm.git

# Navigate to directory
cd her-rhythm

# Install dependencies
npm install

# Start development server
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser to explore the prototype.
